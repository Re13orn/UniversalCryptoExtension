# 表单分组、实时流量筛选与帮助同步

维护构建：`UCE-Revision=2026.10.14.4`。导入格式、动作执行阶段、现有规则参数均保持兼容，旧规则不需要因本次 UI 调整修改。未修改用户当前规则或设置。

## 表单入口与布局

- 加解密：算法、密钥、输入字段和编码放在常用区；字符集与 GCM tag 长度移至“高级参数”。加载非默认高级值时自动展开并标记“已有配置”。切换本地/外部服务、算法和密钥来源仍按原语义展示必需字段。
- 签名：算法、密钥、签名原文与签名前 Header 优先展示；参数排序、URL 编码、分隔符放入高级区；协议助手和案例帮助单独折叠。已有非默认排序/分隔符配置自动展开。
- 规则：域名、路径、方法、Content-Type、工具来源优先展示；Header 条件与正文正则在高级匹配区。已有高级匹配限制自动展开。
- 脚本：模板、插入片段和代码保持直接可见，长篇说明与 API 参考折叠，避免代码区被帮助占满。
- 折叠只改变布局，控件保留在原表单中；保存继续读取全部参数。关闭弹窗和失败提交仍遵循独立草稿机制。
- 加解密、签名表单跟随滚动容器宽度。修复长模板选择器造成横向溢出、GridBag 标签列错误伸展、隐藏分组留下多余间隔的问题。编码选择与模板按钮改为可预测的网格布局。

## 实时流量

搜索范围为记录编号、方法、URL、规则/动作说明和工具来源；按字面文本匹配且不区分大小写，不扫描正文。不执行正则，因此 URL 中的 `[`、`?` 等字符可直接搜索。

可叠加筛选：

| 条件 | 选项 |
|---|---|
| 方向 | 所有、请求、响应 |
| 结果 | 所有、连线已修改、连线未修改、失败 |
| 记录类型 | 所有、报文汇总、动作明细 |

筛选根据实际上下文类型、字节/头部变化及错误状态判断，不根据翻译后的文字猜测。失败独立于“未修改”。显示“可见数 / 已记录数”，仅保留最近 1,000 条的原有上限不变；筛选不丢弃数据，“重置筛选”恢复全部已记录记录。

新记录遵循当前筛选。语言刷新保留查询、筛选、排序与仍可见的选中记录。记录被隐藏或淘汰时清空详情、取消明文预览并禁用相关按钮，防止出现旧详情或清空搜索后自动恢复隐藏选择。列表变动期间不发布瞬间指向其他记录的选中状态。

流量列表仍区分收到的快照、转发快照和明文预览。本次筛选不执行处理器，也不影响客户端收到的加密数据。

## 帮助内容与语言

加解密、签名、字段处理的说明、工具提示，以及规则匹配提示、场景向导摘要和主要测试台说明接入中英文资源。算法名、JSON 参数键、执行阶段与脚本 API 标识保持原文。未改写用户输入或既有脚本代码；其他历史状态文字和示例代码注释没有全量翻译。

脚本动作编辑器与测试台共用 `ScriptHelp`，避免复制的帮助再次分叉；语言切换后选项仍按稳定编号映射，不依赖翻译文字决定配置值。签名说明同样改用固定编号，修复“签名原文与变量”选项错误显示默认说明的问题。

纠正帮助中三项语义：

1. 内置对称加解密基于 JSON 字段；原始密文、AAD 等复杂协议使用脚本，不再建议简单留空字段即可处理任何原始正文。
2. 禁止 `Packages` / Java 访问；二进制使用 `Bytes`，PBKDF2 / AES-GCM 使用 `Crypto`。
3. 脚本 `targetType=field` 不自动抽取字段，需自行解析修改 JSON 并返回完整正文；`null` / `undefined` 保留输入，空字符串清空。

完整构建通过：401 项单元测试（含新增 14 项）、2 项独立 JVM 打包测试、18 项密码服务探测；固定样例在源码/打包运行时分别 34/34 通过；维护脚本 9 项通过。所有测试均无失败、错误或跳过。

新增回归覆盖：高级值折叠保存、两种语言配置值稳定、搜索字面量、叠加筛选、选择隐藏/淘汰、新记录筛选、重置、语言刷新、共享帮助语义和表单宽度。
