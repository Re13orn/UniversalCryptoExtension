# 评审优化说明（2026-10-10）

本文记录扩展的代码评审与修复。

| 条目 | 落地措施 |
|---|---|
| P0-1 | null / undefined 返回 noChange，写回层跳过；不把 undefined 文本写入流量 |
| P0-2 | 私有不可由 JS 捕获的终止信号仅在脚本边界使用，转换成 ScriptTimeoutException，再由处理链捕获 |
| P0-3 | safe standard objects + deny-all ClassShutter；仅通过普通 JS 函数公开声明的辅助方法，不暴露 Java 实例；导入语法/枚举校验、默认禁用、旧新规则对照、文件版本元数据 |
| P1-1 | Java 实现 PBKDF2、AES-GCM、HMAC、随机字节辅助 API，JS 无需调用 JDK provider 对象 |
| P1-2 | 新增 decodeBytes / encodeBytes 与 Bytes API；保留文本兼容方法 |
| P1-3 | 注册只读响应明文编辑器；展示阶段不再原地改写真实流量 |
| P1-4 | 采用回调 messageId 关联，10 分钟生命周期缓存代替容量 1000 LRU，响应结束清理；无 ID 时不采用易碰撞的正文 hash 关联 |
| P1-5 | 上下文保留 byte[]，读写采用 ByteArray，脚本可接收/返回字节数组；文本使用声明 charset，Content-Length 按实际写回字节计算 |
| P1-6 | 动作错误记录到追踪面板并跳过，保留此前及后续成功动作；上下文级故障仍放行原流量 |
| P2-1 | 脚本编译缓存 128 项；继续使用独立作用域，避免不同报文间原型和全局变量污染 |
| P2-2 | Rhino 1.8.1，加载时进行 PBKDF2 + AES-GCM 脚本往返自检 |
| P2-3 | 复用现有 LiveTracePanel，增加逐动作状态、正文长度、耗时与失败信息 |
| P2-4 | 仅接受 process / execute 及现有已知动作名，拒绝拼写错误 |
| P2-5 | Java headers 为大小写不敏感的只读副本；脚本 headers 为只读的大小写不敏感 JS 对象 |

## 与报告建议的差异

- 不使用 `java.lang.*` 等宽泛白名单，因为这会放行 Runtime、Class 等敏感入口。不提供不受约束的 Java 模式。
- 直接将超时 observer 改成 RuntimeException 可能被脚本 catch 吞掉。保留内部终止信号，并仅在脚本处理器边界转换成常规异常，避免进入 Burp。
- Montoya 2023.12.1 没有报告提到的 hasMessageId，也未在普通 initiatingRequest 上暴露 messageId，使用请求/响应回调的 messageId。
- 不复用可变 JS 全局作用域，仅复用编译产物。未提供性能提升百分比，需要在真实规则及流量上测量。

## 验证与边界

原评审优化阶段 `mvn -q package` 成功；268 项测试通过，0 失败、0 错误、0 跳过。已检查打包 JAR 包含响应编辑器和 Crypto 辅助类。测试日志中的动作失败与无效目录错误来自异常路径用例。

自动回归覆盖：无返回值、二进制 Base64、PBKDF2 已知向量、AES-GCM 往返和篡改拒绝、禁止 Java/反射访问、JS try/catch 包裹死循环仍超时、作用域隔离、headers 大小写、GBK 编码、gzip 原始字节保留、原始字节脚本写回、动作失败隔离、碰撞正文按 message ID 分离、1002 个未配对请求保持早期关联、只读响应编辑器保持原响应、导入禁用/校验/元数据兼容。

本次使用本机 JDK 21；项目最低 Java 17。没有宣称支持 JDK 8 / 11，也未执行 JDK 17 / 26 实机矩阵和真实 Burp 高并发压力测试。Rhino observer 限制解释器指令执行时间，不是进程级内存隔离，也不能中断已经进入的 Java 密码计算；PBKDF2 参数和随机字节长度设有上限。

响应编辑器独立创建处理上下文，不重放请求侧 send 动作；依赖 send 阶段随机共享值的响应展示脚本需要从报文可见字段取得参数。实时 response-send 处理支持 message ID 关联的共享数据。超过 10 分钟才到达的响应不再具有此前共享数据。

Rhino 版本发布说明：[Mozilla Rhino releases](https://github.com/mozilla/rhino/releases)。Montoya 响应回调参考：[HttpResponseReceived](https://portswigger.github.io/burp-extensions-montoya-api/javadoc/burp/api/montoya/http/handler/HttpResponseReceived.html)。
