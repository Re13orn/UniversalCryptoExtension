## 使用与兼容

旧规则不需要因本轮 UI 修复修改。实时流量“转发数据”仍对应实际处理链报文，“明文预览”是当前规则的独立本地展示计算；预览不是历史解密结果，也不改变客户端收到的密文。规则变更后需重新生成预览。

测试台和步骤预览运行的是点击时的输入快照。测试台明确选择 external 时仍会调用配置的外部服务；本轮回归未选择外部服务或发送网络请求。取消后台任务会阻止迟到结果显示，但不保证立即终止所有处理器，也不能撤销已发生的外部服务副作用。

设置导出现在导出表单中可见的待保存值；文件导入不会立即生效。复制规则现在默认禁用。表格的排序和筛选不改变规则执行顺序；重建规则页会恢复筛选与选择，列排序仍可重新设置。
